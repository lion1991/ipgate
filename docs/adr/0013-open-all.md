# ADR 0013：放行所有 IP（SSH 除外）

状态：已定案（待实施，进度见 `docs/plans/open-all.md`）
日期：2026-11-09
关联：ADR 0002（ruleset 布局、过期由 agent 权威）、0008（转发名单门）、0011（公开端口、SSH 暴露只在「安全」里管）、0012（敲门）

## 背景

用户要一键让主机对所有 IP 开放（排障、迁移这类场景）。「公开端口」只能按端口放。手动把 `0.0.0.0/0`、`::/0` 加进名单虽然能全开，但有两个问题：

1. 名单规则不分端口，SSH「仅名单可连」被绕过，开关却仍显示「仅名单」——正是 ADR 0011 决策 4 拒绝的情况。
2. 名单元素内联在整表事务里（`nft -f`），interval set 不接受重叠元素，`/0` 和任何已有条目都重叠，整表重建会被拒（已实测，见「顺带发现」）。

## 决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | agent 新增独立开关「放行所有 IP」，存 `state.json`（带可选到期时间），**不往名单 set 里加 `/0`** | 不碰 interval set 的重叠问题；SSH 能单独排除 |
| 2 | 语义：视同所有 IP 都在名单里，**SSH 除外**——所有端口、ping、转发名单门都放行；SSH 仍按「安全」里的「仅名单可连」（用户拍板） | 维持「SSH 暴露只在『安全』里管」 |
| 3 | input 链末尾追加 `meta l4proto != tcp accept` 与 `tcp dport != <ssh> accept`；转发门在末尾 drop 前加 `ct state new ct status dnat accept`。开关关时不渲染，ruleset 与之前逐字节一致 | 名单内源 IP 照常先命中名单规则（含 SSH）；关时零行为变化 |
| 4 | 时长可选 15 分钟 / 1 小时 / 24 小时 / 永久（用户拍板可选永久）。到期由 agent 对账循环检查并整表重建关掉；启动重建时已过期直接按关处理 | 内核规则不会自己过期；与 ADR 0002「agent 对账为权威」一致 |
| 5 | 开、关、到期都走整表重建（`apply_ruleset`），先落内核再落盘，失败不改设置 | 与 SSH 暴露、转发名单门、公开端口同一套顺序与锁 |
| 6 | 名单拒绝新增 `/0` 条目，提示改用本开关；已存在的不迁移 | 堵住绕过 SSH「仅名单」的口子 |
| 7 | `AgentSettings` 上报开关状态与到期时间，旧 agent 为 `None`，客户端据此提示升级 | 与 ADR 0008、0011 的兼容口径一致 |
| 8 | 客户端只做 Mac 原生，移动端（Tauri）不动（用户拍板：Mac 上不用 Tauri，移动平台不动） | |
| 9 | Mac：开关放「安全」分区，确认框里选时长；开着时名单页顶部常驻横幅（剩余时间 + 「关闭」），右栏「访问与安全」同步显示 | 全开是高风险状态，必须一直看得见、一键能关 |

## 已否决

- **往名单加 `0.0.0.0/0`、`::/0`**：绕过 SSH「仅名单」；与已有条目重叠可能让整表事务被拒。
- **SSH 一起放开**（用户否决）：会让「安全」里的 SSH 开关显示与实际不符。
- **只给到期档位、不提供永久**：用户要可选永久。

## 已知限制

- 移动端看不到这个开关的状态，但 agent 照常执行。
- 到期关闭最多晚一个对账周期（默认 30 秒）；agent 停止期间不会到期关闭，重启后按到期时间处理。
- 开、关、到期都是整表重建，会清空 `knock4/knock6`（同 ADR 0012 已知限制），已建立的连接不受影响。

## 验证

- 2026-11-09 OrbStack 容器（内核 7.2）：agent 实际渲染的 ruleset（仅名单 + 敲门 + 转发门）加上决策 3 的规则。trixie（nft 1.1.3）netns 拓扑实测：未放行源 SSH 不通，其他 TCP、UDP、ping、DNAT 转发都通；源在名单里时 SSH 也通；敲门入 `knock4` 后 SSH 通。bookworm（nft 1.0.6）`nft -c` 通过。
- 未验证：el7（nft 0.8）、真机内核、IPv6 流量。

## 顺带发现：名单重叠条目让整表落地失败（现存 bug）

CIDR 之间只有包含或不相交两种关系。名单里一旦有互相包含的条目（如 `1.2.3.0/24` 与 `1.2.3.4`），nft 1.0.6 / 1.1.3 都会拒绝：增量 `add element` 报 `interval overlaps with an existing one`，整表 `nft -f` 报 `conflicting intervals specified`。agent 先落盘后落内核，所以条目留在存储里，之后：

- 改 SSH / 转发门开关、改公开端口都会失败；
- agent 重启时启动重建失败，进程退出，客户端连不上；主机重启后连 ipgate 表都没有，整机不设防。
