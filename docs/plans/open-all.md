# 放行所有 IP 实施方案（ADR 0013）

定案见 `docs/adr/0013-open-all.md`。每步单独提交、可单独回滚。

## 步骤

1. **nft 可行性验证**：在 Linux 容器里用真实 nft 校验开关规则（`nft -c` + 实际流量：非 SSH 端口与 ping 可达、SSH 仍按「仅名单」、转发门放行）。顺带确认名单里重叠条目（如 `1.2.3.0/24` 与 `1.2.3.4`）会不会让整表事务被拒——这是现存隐患，确认后单独处理。
2. **agent + proto**（agent 0.2.12）：`state.json` 开关与到期时间；RPC 开 / 关；`AgentSettings` 上报；input 链与转发门渲染；对账循环到期关闭；名单拒绝新增 `/0`；`status` 打印开关状态。
3. **客户端 core + ffi**：暴露开 / 关与设置字段；旧 agent 提示升级。
4. **Mac 客户端**：「安全」开关 + 确认框选时长；名单页横幅（剩余时间 + 关闭）；右栏同步；等待期间有动画反馈。
5. **发布**：agent 先以预发布发出，自己试用没问题再转正式。
