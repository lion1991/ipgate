# 放行所有 IP 实施方案（ADR 0013）

定案见 `docs/adr/0013-open-all.md`。每步单独提交、可单独回滚。

## 步骤

1. **nft 可行性验证**：✅ 2026-11-09 OrbStack 容器（内核 7.2；trixie nft 1.1.3 实测流量，bookworm nft 1.0.6 `nft -c`）。agent 实际渲染的 ruleset（仅名单 + 敲门 + 转发门）加上开关规则后：未放行源 SSH 不通、其他 TCP / UDP / ping / DNAT 转发都通；源在名单里 SSH 也通；敲门照常生效。顺带确认名单重叠条目是现存 bug（见 ADR 0013「顺带发现」），单独修。
2. **名单重叠修复**：拒绝新增互相包含的条目；旧数据只落外层（见 ADR 0013「顺带发现」）。
3. **agent + proto**（agent 0.2.12，与第 2 步同版发布）：`state.json` 开关与到期时间；RPC 开 / 关；`AgentSettings` 上报；input 链与转发门渲染；对账循环到期关闭；名单拒绝新增 `/0`；`status` 打印开关状态。
4. **客户端 core + ffi**：暴露开 / 关与设置字段；旧 agent 提示升级。
5. **Mac 客户端**：「安全」开关 + 确认框选时长；名单页横幅（剩余时间 + 关闭）；右栏同步；等待期间有动画反馈。
6. **发布**：agent 先以预发布发出，自己试用没问题再转正式。
